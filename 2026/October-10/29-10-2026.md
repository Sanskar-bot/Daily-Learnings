## Part 1 — Max Consecutive Ones III (Sliding Window with Flip Budget)

**Problem:** Given a binary array and integer `k`, return the length of the longest subarray containing only 1s if you can flip at most `k` zeros.

**Insight:** Instead of thinking about flipping zeros, think of `k` as a **budget of zeros** you're allowed inside the window. The window is valid as long as the count of zeros inside it is ≤ k.

```python
class Solution:
    def longestOnes(self, nums: list[int], k: int) -> int:
        left = 0
        zeros = 0
        maxlen = 0

        for right in range(len(nums)):
            if nums[right] == 0:
                zeros += 1

            while zeros > k:          # window has too many zeros — shrink from left
                if nums[left] == 0:
                    zeros -= 1
                left += 1

            maxlen = max(maxlen, right - left + 1)

        return maxlen
```

**Why this works:** The window expands right unconditionally. When the zero count exceeds the budget `k`, we shrink from the left until it's valid again. At each step, we record the window size.

**Complexity:** O(n) time — `left` and `right` both only move forward. O(1) space.

## Part 2 — Sliding Window Pattern Consolidation

Three sliding window variants now covered:

| Problem | Window condition | Shrink trigger |
|---|---|---|
| Longest Substring No Repeat | `seen` set has no duplicates | Duplicate entered |
| Max Consecutive Ones III | `zeros ≤ k` | Zero budget exceeded |
| Sliding Window Maximum | Deque maintains decreasing order | Front index out of window |

The key insight across all three: **expand right unconditionally, shrink left reactively when the window violates its condition.**
