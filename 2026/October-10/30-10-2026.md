## Part 1 — Reverse Linked List (Iterative Pointer Reversal)

**Key insight:** To reverse a list, walk forward while flipping each `next` pointer to point backward. The trick is saving `cur.next` before overwriting it.

```python
def reverseList(self, head):
    pre = None
    cur = head
    while cur:
        nxt = cur.next      # save forward reference before we lose it
        cur.next = pre      # flip the pointer
        pre = cur           # advance pre
        cur = nxt           # advance cur
    return pre              # pre is now the new head
```

Handles empty list and single-node list with no special cases. **O(n) time, O(1) space.**

## Part 2 — Linked List Cycle (Floyd's Cycle Detection — Phase 1)

**Insight:** A slow pointer (1 step) and a fast pointer (2 steps) are like two runners on a track. If there's a cycle, fast will eventually lap slow and they'll meet. If there's no cycle, fast reaches `None`.

```python
def hasCycle(self, head):
    slow = fast = head
    while fast and fast.next:
        fast = fast.next.next
        slow = slow.next
        if fast == slow:
            return True
    return False
```

The guard `fast and fast.next` prevents both `fast.next` and `fast.next.next` from being called on `None`. **O(n) time, O(1) space.**

## Part 3 — Linked List Cycle II (Floyd's — Phase 2: Find Entry Point)

After Phase 1 finds the meeting point, Phase 2 finds the **cycle entry node**.

**The math:** If the meeting point is at distance `d` into the cycle, and the cycle entry is at distance `F` from head, then resetting one pointer to `head` and advancing both by 1 step at a time causes them to meet exactly at the entry node. (Proof relies on `F ≡ C - d (mod C)`.)

```python
def detectCycle(self, head):
    slow = fast = head
    while fast and fast.next:
        fast = fast.next.next
        slow = slow.next
        if fast == slow:
            slow2 = head
            while slow2 != slow:    # Phase 2: find entry
                slow2 = slow2.next
                slow = slow.next
            return slow
    return None
```

**O(n) time, O(1) space.**

## Part 4 — Middle of the Linked List (Slow/Fast Pointers)

Same slow/fast pointer idea — when `fast` reaches the end, `slow` is at the middle:

```python
def middleNode(self, head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow
```

For even-length lists (e.g. `[1,2,3,4]`), returns the **second** middle node (`3`) — which is what LeetCode expects. **O(n) time, O(1) space.**

## Part 5 — Merge Two Sorted Lists (Two Pointers)

Build a new list by always picking the smaller head from the two lists:

```python
def mergeTwoLists(self, l1, l2):
    dummy = ListNode(0)
    cur = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            cur.next = l1
            l1 = l1.next
        else:
            cur.next = l2
            l2 = l2.next
        cur = cur.next
    cur.next = l1 or l2     # attach the remaining non-empty list
    return dummy.next
```

The **dummy head** trick eliminates special-casing the first node. **O(n+m) time, O(1) space.**

## Part 6 — Remove Nth Node From End (One-Pass Two Pointers)

**Gap trick:** Send a `fast` pointer `n` steps ahead. Then advance both `slow` and `fast` together — when `fast` hits the end, `slow` is exactly at the node before the target.

```python
def removeNthFromEnd(self, head, n):
    dummy = ListNode(0, head)
    slow = fast = dummy
    for _ in range(n + 1):    # +1 so slow lands before the target
        fast = fast.next
    while fast:
        slow = slow.next
        fast = fast.next
    slow.next = slow.next.next
    return dummy.next
```

**O(L) time, O(1) space** — single pass.

## Part 7 — Intersection of Two Linked Lists (Switch-Heads Trick)

**Insight:** If pointer A walks list A then list B, and pointer B walks list B then list A, they both travel the same total distance and meet at the intersection node (or both reach `None` if no intersection).

```python
def getIntersectionNode(self, headA, headB):
    a, b = headA, headB
    while a != b:
        a = a.next if a else headB
        b = b.next if b else headA
    return a
```

**O(n+m) time, O(1) space.**
