## Part 1 — Doctor Portal UI Bug Fixes

Three silent bugs in the doctor portal that had accumulated:

#### Patient Name Missing in My Requests Table

The `my_requests` SQL JOIN was selecting `doctor.username` instead of `patient.name`
for the requesting column. The frontend template was therefore rendering `null` for
every row. Fixed by correcting the JOIN alias:

```sql
-- Before (wrong alias)
SELECT d.name AS patient_name ...

-- After (correct alias)
SELECT p.name AS patient_name ...
JOIN users p ON ar.patient_id = p.user_id
```

#### Access Denied on Clinical Notes Page

Authorized doctors were hitting a 403 on `/notes` because the route guard was checking
`doctor_code` from the session against the database, but the session key was stored as
`doctor_id` after a previous refactor. Fixed by aligning the session key name everywhere.

#### `view_patient` URL Construction

The "View Patient" button was building `/view/patient/<username>` but the registered
Flask route was `/view_patient/<username>` (underscore, not slash). Fixed the template
`url_for` call. Also removed all emoji characters from UI templates for a cleaner,
more professional look.

## Part 2 — Allergy / Drug-Interaction Safety Check

The most significant feature of the day. When a doctor writes a new prescription, the
system now cross-checks it against the patient's recorded allergies before saving.

#### Data Model — Cross-Reactivity Table

```python
# server/emr/models.py

ALLERGY_CROSS_REACTIVITY = {
    "penicillin":    ["amoxicillin", "ampicillin", "piperacillin", "cephalosporins"],
    "sulfa":         ["sulfamethoxazole", "trimethoprim-sulfamethoxazole", "furosemide"],
    "nsaids":        ["ibuprofen", "naproxen", "aspirin", "diclofenac", "celecoxib"],
    "cephalosporins":["cefazolin", "cephalexin", "ceftriaxone"],
    "latex":         ["banana", "avocado", "kiwi"],   # latex-fruit syndrome
    # ...
}

def _norm_allergy_list(raw: str) -> list[str]:
    """Lowercase, strip, split on comma/semicolon."""
    return [a.strip().lower() for a in re.split(r"[,;]", raw or "") if a.strip()]

def check_allergy_conflicts(patient_allergies: str, drug_name: str) -> dict:
    """
    Returns {"conflict": False} or
    {"conflict": True, "severity": "danger"|"warning", "matched_allergy": str, "reason": str}
    """
    norms = _norm_allergy_list(patient_allergies)
    drug  = drug_name.strip().lower()
    for allergy in norms:
        # Direct match
        if allergy in drug or drug in allergy:
            return {"conflict": True, "severity": "danger",
                    "matched_allergy": allergy, "reason": "direct_match"}
        # Cross-reactivity
        for family, cross_list in ALLERGY_CROSS_REACTIVITY.items():
            if allergy == family or allergy in cross_list:
                if drug in cross_list or drug == family:
                    return {"conflict": True, "severity": "warning",
                            "matched_allergy": allergy, "reason": f"cross_reactivity:{family}"}
    return {"conflict": False}
```

#### API Response — 409 Conflict

```python

conflict = check_allergy_conflicts(profile.allergies, body["drug_name"])
```

## Part 3 — 7-Section Health Record Page

Built a comprehensive EMR landing page (`emr.html`) that surfaces all 7 data categories
in collapsible sections with a profile-completeness widget at the top.

#### Sections

| # | Section | Data Source |
|---|---------|-------------|
| 1 | Personal Info / Demographics | `patient_profile` table |
| 2 | Allergies | `profile.allergies` (comma-separated) |
| 3 | Active Medications | `prescriptions` WHERE `status = 'active'` |
| 4 | Conditions / Diagnoses | `conditions` table |
| 5 | Lab Reports | `lab_reports` table |
| 6 | Prescriptions (full history) | `prescriptions` table |
| 7 | Encounter / Visit History | `encounters` table |

#### Profile Completeness Widget

```javascript
function computeCompleteness(profile) {
  const fields = [
    profile.name, profile.dob, profile.blood_type,
    profile.allergies, profile.emergency_contact,
    profile.phone, profile.address
  ];
  const filled = fields.filter(f => f && String(f).trim()).length;
  return Math.round((filled / fields.length) * 100);
}

// Renders a circular progress ring with CSS conic-gradient
function renderRing(pct) {
  ring.style.background =
    `conic-gradient(#22c55e ${pct}%, #e5e7eb ${pct}%)`;
  label.textContent = `${pct}% complete`;
}
```

Missing fields show a contextual prompt: *"Add your blood type →"* linking directly
to the edit form for that field.
