## Part 1 — Trapping Rain Water 🔴 Hard (Two Pointers, O(1) Space)

**Problem:** Given elevation heights, compute total trapped water.

**Formula:** Water at index `i` = `min(max_left, max_right) - height[i]`.

**Naive approach:** Precompute `left_max[]` and `right_max[]` arrays — O(n) time but O(n) space.

**Optimised (Two Pointers):** When `height[left] < height[right]`, the right boundary is guaranteed to be at least as tall as the right max (since we're moving from outside in). So we can safely process the left side using only `left_max`.

```python
def trap(self, height):
    left, right = 0, len(height) - 1
    left_max = right_max = 0
    water = 0
    while left < right:
        if height[left] < height[right]:
            if height[left] >= left_max:
                left_max = height[left]      # new max on left
            else:
                water += left_max - height[left]  # trapped water
            left += 1
        else:
            if height[right] >= right_max:
                right_max = height[right]
            else:
                water += right_max - height[right]
            right -= 1
    return water
```

**Key insight:** Process the side with the smaller boundary because the larger boundary is already tall enough to support the water level on the smaller side. **O(n) time, O(1) space.**

## Part 2 — Set Matrix Zeroes (In-Place O(1) Space)

**Problem:** If a cell is 0, set its entire row and column to 0. Do it in-place.

**Trick:** Use the first row and first column as markers. Before that, record whether row 0 or col 0 themselves contain a zero.

```python
def setZeroes(self, matrix):
    rows, cols = len(matrix), len(matrix[0])
    first_row_zero = any(matrix[0][c] == 0 for c in range(cols))
    first_col_zero = any(matrix[r][0] == 0 for r in range(rows))

    # Use row 0 and col 0 as markers
    for r in range(1, rows):
        for c in range(1, cols):
            if matrix[r][c] == 0:
                matrix[r][0] = 0
                matrix[0][c] = 0

    # Zero out cells based on markers
    for r in range(1, rows):
        for c in range(1, cols):
            if matrix[r][0] == 0 or matrix[0][c] == 0:
                matrix[r][c] = 0

    if first_row_zero:
        for c in range(cols): matrix[0][c] = 0
    if first_col_zero:
        for r in range(rows): matrix[r][0] = 0
```

**O(m·n) time, O(1) space** — no extra arrays.

## Part 3 — Reverse Words in a String (Two Pointers)

Split on whitespace (handles multiple spaces), reverse the word list, rejoin:

```python
def reverseWords(self, s):
    words = s.split()      # splits on any whitespace and strips leading/trailing
    return ' '.join(reversed(words))
```

## Part 5 — Roman to Integer (Right-to-Left Scan)

**Rule:** A smaller value before a larger one means subtraction (e.g. `IV = 4`). Scan right-to-left — if the current value is less than the previous, subtract it; otherwise add it.

```python
def romanToInt(self, s):
    val = {'I':1,'V':5,'X':10,'L':50,'C':100,'D':500,'M':1000}
    result = 0
    prev = 0
    for ch in reversed(s):
        curr = val[ch]
        if curr < prev:
            result -= curr
        else:
            result += curr
        prev = curr
    return result
```

## Part 6 — String to Integer (atoi) — Edge Cases

**Steps:** Strip leading whitespace → read optional sign → read digits → clamp to 32-bit integer range.

```python
def myAtoi(self, s):
    s = s.lstrip()
    if not s: return 0
    sign = -1 if s[0] == '-' else 1
    if s[0] in '+-': s = s[1:]
    num = 0
    for ch in s:
        if not ch.isdigit(): break
        num = num * 10 + int(ch)
    num *= sign
    return max(-2**31, min(2**31 - 1, num))
```

**Most common failure:** Not handling leading whitespace, missing sign handling, or forgetting the 32-bit clamp.

## Part 7 — Longest Common Prefix (Shrinking Prefix)

Take the first word as the prefix. For each subsequent word, shrink the prefix until it matches the start of that word:

```python
def longestCommonPrefix(self, strs):
    prefix = strs[0]
    for s in strs[1:]:
        while not s.startswith(prefix):
            prefix = prefix[:-1]
            if not prefix: return ""
    return prefix
```

## Part 8 — Process Tasks Using Servers 🟡 Medium (Two Min-Heaps)

**Problem:** Assign tasks to servers; each server has a weight and index; use the smallest weight (then smallest index) free server for each task.

**Two heaps:**
- `free`: min-heap of `(weight, index)` — available servers
- `busy`: min-heap of `(free_at_time, weight, index)` — in-use servers

```python
import heapq
def assignTasks(self, servers, tasks):
    free  = [(w, i) for i, w in enumerate(servers)]
    heapq.heapify(free)
    busy  = []
    result = []
    for t, task in enumerate(tasks):
        # release servers whose task has finished
        while busy and busy[0][0] <= t:
            _, w, i = heapq.heappop(busy)
            heapq.heappush(free, (w, i))
        if free:
            w, i = heapq.heappop(free)
            heapq.heappush(busy, (t + task, w, i))
        else:
            finish, w, i = heapq.heappop(busy)      # wait for earliest free
            heapq.heappush(busy, (finish + task, w, i))
            i_result = i  # server index
        result.append(i)
    return result
```

**O((n + m) log n) time** (n = servers, m = tasks). The two-heap pattern is a classic for scheduling problems.
