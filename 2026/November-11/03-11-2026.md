## Part 1 — Balanced Binary Tree (Bottom-Up with Early Exit)

**Problem:** Return `True` if the tree is height-balanced (every node's left and right subtrees differ in height by at most 1).

**Naive approach:** Call `maxDepth` on every node — O(n²) for a skewed tree because heights are recomputed.

**Optimised:** Return `-1` as a sentinel meaning "already unbalanced" and propagate it upward immediately (early exit):

```python
def isBalanced(self, root):
    def dfs(node):
        if not node:
            return 0
        left = dfs(node.left)
        if left == -1: return -1          # propagate early exit
        right = dfs(node.right)
        if right == -1: return -1
        if abs(left - right) > 1:
            return -1                     # this node is unbalanced
        return 1 + max(left, right)       # return height normally
    return dfs(root) != -1
```

**O(n) time** — single pass, no recomputation. **O(h) space.**

## Part 2 — Binary Tree Zigzag Level Order Traversal

Standard BFS level-order, but alternate the direction each level by reversing odd-indexed levels:

```python
def zigzagLevelOrder(self, root):
    if not root: return []
    result, queue = [], deque([root])
    level_num = 0
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left:  queue.append(node.left)
            if node.right: queue.append(node.right)
        result.append(level if level_num % 2 == 0 else level[::-1])
        level_num += 1
    return result
```

**O(n) time, O(n) space** (the queue holds at most one full level at a time).

## Part 3 — Path Sum (Root-to-Leaf DFS)

**Problem:** Does any root-to-leaf path have a total equal to `targetSum`?

**Key:** Subtract the current node's value from the target as you descend. At a leaf, check if the remainder is 0.

```python
def hasPathSum(self, root, targetSum):
    if not root:
        return False
    targetSum -= root.val
    if not root.left and not root.right:   # leaf
        return targetSum == 0
    return (self.hasPathSum(root.left,  targetSum) or
            self.hasPathSum(root.right, targetSum))
```

The leaf check (`not left and not right`) is critical — without it, an internal node with one child and a matching cumulative sum would incorrectly return `True`. **O(n) time, O(h) space.**

## Part 4 — Graph DFS: Number of Provinces (Connected Components)

**Problem:** Given an adjacency matrix, count the number of connected components.

**Pattern:** DFS from every unvisited node, marking all reachable nodes visited — each DFS call explores one component.

```python
def findCircleNum(self, isConnected):
    n = len(isConnected)
    visited = [False] * n
    def dfs(i):
        visited[i] = True
        for j in range(n):
            if isConnected[i][j] == 1 and not visited[j]:
                dfs(j)
    provinces = 0
    for i in range(n):
        if not visited[i]:
            dfs(i)
            provinces += 1
    return provinces
```

**O(n²) time** (adjacency matrix — each row is scanned). **O(n) space** (visited array + call stack).

## Part 5 — Max Area of Island (Grid DFS)

**Pattern:** DFS from each unvisited land cell (`1`), marking visited by setting to `0` (sink), and returning the size of the island found.

```python
def maxAreaOfIsland(self, grid):
    rows, cols = len(grid), len(grid[0])
    def dfs(r, c):
        if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] == 0:
            return 0
        grid[r][c] = 0           # mark visited by sinking
        return 1 + dfs(r+1,c) + dfs(r-1,c) + dfs(r,c+1) + dfs(r,c-1)
    return max((dfs(r, c) for r in range(rows) for c in range(cols)), default=0)
```

**O(rows × cols) time and space.**

## Part 6 — Surrounded Regions (DFS from Borders)

**Key insight:** Any `O` connected to a border cannot be flipped. So:
1. DFS from all border `O` cells, marking them `S` (safe)
2. Flip all remaining `O` to `X`
3. Restore all `S` back to `O`

```python
def solve(self, board):
    rows, cols = len(board), len(board[0])
    def mark_safe(r, c):
        if r < 0 or r >= rows or c < 0 or c >= cols or board[r][c] != 'O':
            return
        board[r][c] = 'S'
        for dr, dc in [(1,0),(-1,0),(0,1),(0,-1)]:
            mark_safe(r+dr, c+dc)
    for r in range(rows):
        for c in range(cols):
            if (r in (0, rows-1) or c in (0, cols-1)) and board[r][c] == 'O':
                mark_safe(r, c)
    for r in range(rows):
        for c in range(cols):
            if board[r][c] == 'O': board[r][c] = 'X'
            elif board[r][c] == 'S': board[r][c] = 'O'
```

The "DFS from borders" approach avoids checking every `O`'s connectivity to the border individually. **O(rows × cols) time, O(rows × cols) space** (recursion stack).

## Part 7 — Add Two Numbers (Linked List Digit Addition)

Simulate digit-by-digit addition with a carry, traversing both lists simultaneously:

```python
def addTwoNumbers(self, l1, l2):
    dummy = ListNode(0)
    cur = dummy
    carry = 0
    while l1 or l2 or carry:
        v1 = l1.val if l1 else 0
        v2 = l2.val if l2 else 0
        total = v1 + v2 + carry
        carry = total // 10
        cur.next = ListNode(total % 10)
        cur = cur.next
        if l1: l1 = l1.next
        if l2: l2 = l2.next
    return dummy.next
```

The `while l1 or l2 or carry` condition handles lists of different lengths and a final carry (e.g. `99 + 1 = 100` produces a third node). **O(max(n,m)) time, O(max(n,m)) space.**
