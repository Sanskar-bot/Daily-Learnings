## Part 1 — Valid Palindrome II (Try Skipping Left or Right)

**Problem:** Given a string, return `True` if it can become a palindrome by removing at most one character.

**Approach:** Use two pointers converging from both ends. When a mismatch is found, we have exactly one deletion to use — try skipping the left character, or try skipping the right character. If either resulting substring is a palindrome, return `True`.

```python
def validPalindrome(self, s):
    def isPalin(lo, hi):
        while lo < hi:
            if s[lo] != s[hi]:
                return False
            lo += 1
            hi -= 1
        return True

    left, right = 0, len(s) - 1
    while left < right:
        if s[left] != s[right]:
            # try skipping left char or skipping right char
            return isPalin(left + 1, right) or isPalin(left, right - 1)
        left += 1
        right -= 1
    return True
```

**Key insight:** We only need to check two substrings at the first mismatch — not at every position. If neither works, there's no valid single deletion.

**Complexity:** O(n) time, O(1) space.

## Part 2 — Count Zero Request Servers (Sliding Window on Time Events)

**Problem:** Given server logs `(time, server_id)` and queries `[l, r, x]` (find servers with zero requests in `[l-x, r]`), answer all queries efficiently.

**Approach:** Offline processing — sort queries by their right endpoint. Use a sliding window over the sorted logs and a frequency map to track how many servers are active in the window.

```python
def countServers(self, n, logs, x, queries):
    logs.sort(key=lambda e: e[0])
    indexed_queries = sorted(enumerate(queries), key=lambda q: q[1])

    result = [0] * len(queries)
    freq = {}           # server_id → count in window
    left = 0            # pointer into sorted logs

    for orig_idx, (r, q_x) in indexed_queries:  # q_x is the window size
        l = r - q_x                              # window start = r - x

        # expand right: add logs with time <= r
        # (handled implicitly as we process queries in order of r)

        # shrink left: remove logs with time < l
        while left < len(logs) and logs[left][0] < l:
            sid = logs[left][1]
            freq[sid] -= 1
            if freq[sid] == 0:
                del freq[sid]
            left += 1

        # count servers with zero requests = total servers - active servers
        result[orig_idx] = n - len(freq)

    return result
```

**Pattern:** Offline sliding window — sort both events and queries, sweep together.

**Complexity:** O((m + q) log(m + q)) — m = logs, q = queries.

| Valid Palindrome II | `left`, `right` converge | Try skip-left or skip-right |
| Longest Palindromic Substring | Expand from center | Try odd/even center |

## Questions I Still Have
