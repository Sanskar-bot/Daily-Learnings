## Part 1 — Maximum Depth of Binary Tree

**Pattern:** Return the depth from each node — 0 for `None`, or `1 + max(left_depth, right_depth)`.

```python
def maxDepth(self, root):
    if not root:
        return 0
    return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```

**O(n) time** — every node is visited once. **O(h) space** — call stack height equals tree height (O(n) worst case for skewed tree, O(log n) for balanced).

---

## Part 2 — Diameter of Binary Tree

**Key insight:** The diameter is the **longest path between any two nodes**, which may or may not pass through the root. For each node, the path through it has length `left_depth + right_depth`.

```python
def diameterOfBinaryTree(self, root):
    self.ans = 0
    def dfs(node):
        if not node:
            return 0
        left = dfs(node.left)
        right = dfs(node.right)
        self.ans = max(self.ans, left + right)   # update global max at each node
        return 1 + max(left, right)              # return depth to parent
    dfs(root)
    return self.ans
```

The function returns **depth** to the parent but updates the **diameter** as a side effect. This bottom-up combination pattern appears in many tree problems.

**O(n) time, O(h) space.**

## Part 3 — Invert Binary Tree

**Pattern:** Swap left and right children at every node recursively.

```python
def invertTree(self, root):
    if not root:
        return None
    root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
    return root
```

Python's tuple unpacking means both recursive calls complete before the assignment — no temporary variable needed. **O(n) time, O(h) space.**

## Part 4 — Symmetric Tree

**Pattern:** Compare mirror pairs — the left subtree's left child must equal the right subtree's right child, and vice versa.

```python
def isSymmetric(self, root):
    def isMirror(left, right):
        if not left and not right: return True
        if not left or not right:  return False
        return (left.val == right.val and
                isMirror(left.left, right.right) and   # outer pair
                isMirror(left.right, right.left))      # inner pair
    return isMirror(root.left, root.right)
```

The two recursive calls check the **outer pair** (left-left vs right-right) and the **inner pair** (left-right vs right-left). **O(n) time, O(h) space.**

## Part 5 — Lowest Common Ancestor of a Binary Tree

**Pattern:** Return `p` or `q` if found, `None` otherwise. If both left and right subtrees return a non-`None` value, the current node is the LCA.

```python
def lowestCommonAncestor(self, root, p, q):
    if not root or root == p or root == q:
        return root                        # base case: found one or hit a leaf
    left  = self.lowestCommonAncestor(root.left,  p, q)
    right = self.lowestCommonAncestor(root.right, p, q)
    if left and right:
        return root                        # p in one subtree, q in the other
    return left or right                   # one side found both (one is ancestor of the other)
```

**O(n) time** — may visit every node in the worst case. **O(h) space.**

## Pattern: Bottom-Up DFS

All five problems use the same structure:
1. Base case: return a sentinel for `None` nodes (0 for depth, `None` for LCA)
2. Recurse left and right, collecting return values
3. Combine the return values at the current node
4. Return something useful to the parent

```
result = combine(left_result, right_result)
update_global_answer_if_needed(result)
return result_for_parent
```

The diameter problem is the clearest example: `result_for_parent = depth` but `answer = diameter`.
