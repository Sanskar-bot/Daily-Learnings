## Part 1 — Backtracking: The Template

Backtracking is **systematic exhaustive search with pruning**. The template is always the same:

```
def backtrack(start, current_path):
    if base_case_reached:
        record(current_path)
        return
    for each_choice in choices_from(start):
        make_choice
        backtrack(next_start, updated_path)
        undo_choice        # ← this is the "backtrack" step
```

The **undo step** is what distinguishes backtracking from plain recursion — the path is shared across calls, so each recursive call must restore the state it changed before returning.

## Part 2 — Combination Sum (Reuse Allowed)

**Key difference from other backtracking:** the same element can be reused, so we pass `start = i` (not `i + 1`) to the recursive call.

```python
def combinationSum(self, candidates, target):
    result = []
    def backtrack(start, path, remaining):
        if remaining == 0:
            result.append(list(path))
            return
        for i in range(start, len(candidates)):
            if candidates[i] > remaining:
                break           # pruning: sorted array, no need to continue
            path.append(candidates[i])
            backtrack(i, path, remaining - candidates[i])  # i not i+1 → reuse allowed
            path.pop()
    candidates.sort()
    backtrack(0, [], target)
    return result
```

Sorting enables the `break` pruning — once a candidate exceeds the remaining sum, all larger candidates will too. **O(n^(T/M)) time** (T = target, M = min candidate).

## Part 3 — Letter Combinations of a Phone Number

Classic backtracking over a phone digit map. For each digit, try every letter it maps to and recurse on the next digit:

```python
phone_map = {"2":"abc","3":"def","4":"ghi","5":"jkl",
             "6":"mno","7":"pqrs","8":"tuv","9":"wxyz"}

def backtrack(idx, path):
    if idx == len(digits):
        result.append("".join(path))
        return
    for ch in phone_map[digits[idx]]:
        path.append(ch)
        backtrack(idx + 1, path)
        path.pop()
```

**O(4^n · n) time** (4 is max letters per digit, n = number of digits).

## Part 4 — Palindrome Partitioning

Backtrack over all possible cuts. At each position, try every prefix — if it's a palindrome, include it in the partition and recurse on the rest:

```python
def backtrack(start, path):
    if start == len(s):
        result.append(list(path))
        return
    for end in range(start + 1, len(s) + 1):
        piece = s[start:end]
        if piece == piece[::-1]:    # palindrome check
            path.append(piece)
            backtrack(end, path)
            path.pop()
```

## Part 5 — Word Search (Backtracking on a Grid)

Mark a cell as visited before recursing (to prevent reuse in the same path), then restore it after:

```python
def exist(self, board, word):
    rows, cols = len(board), len(board[0])
    def dfs(r, c, idx):
        if idx == len(word):
            return True
        if r < 0 or r >= rows or c < 0 or c >= cols or board[r][c] != word[idx]:
            return False
        tmp = board[r][c]
        board[r][c] = '#'           # mark visited
        found = (dfs(r+1,c,idx+1) or dfs(r-1,c,idx+1) or
                 dfs(r,c+1,idx+1) or dfs(r,c-1,idx+1))
        board[r][c] = tmp           # restore (backtrack)
        return found
    for r in range(rows):
        for c in range(cols):
            if dfs(r, c, 0):
                return True
    return False
```

## Part 6 — Binary Tree Traversals (Inorder, Preorder, Postorder)

The three DFS traversal orders differ only in **when you process the root** relative to the children:

| Traversal | Order | Use case |
|---|---|---|
| Inorder | Left → Root → Right | BST gives sorted sequence |
| Preorder | Root → Left → Right | Copy tree, serialize |
| Postorder | Left → Right → Root | Delete tree, evaluate expression |

```python
# Inorder: Left, Root, Right
def inorderTraversal(self, root):
    result = []
    def dfs(node):
        if not node: return
        dfs(node.left)
        result.append(node.val)   # root between children
        dfs(node.right)
    dfs(root)
    return result
```

## Part 7 — Binary Tree Level Order Traversal (BFS)

Use a queue — process level by level:

```python
from collections import deque
def levelOrder(self, root):
    if not root: return []
    result, queue = [], deque([root])
    while queue:
        level = []
        for _ in range(len(queue)):   # process exactly one level
            node = queue.popleft()
            level.append(node.val)
            if node.left:  queue.append(node.left)
            if node.right: queue.append(node.right)
        result.append(level)
    return result
```

**O(n) time and space** — every node is enqueued and dequeued once.
