## Part 1 — Binary Search (Classic Template)

**Core idea:** Eliminate half the search space each step by comparing the middle element to the target.

```python
def search(self, nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if target > nums[mid]:
            lo = mid + 1      # discard left half
        else:
            hi = mid - 1      # discard right half
    return -1
```

**Common mistakes:**
- `lo < hi` vs `lo <= hi` — use `<=` to handle the single-element case (`lo == hi`)
- `mid = (lo + hi) // 2` — safe in Python (no integer overflow). In Java/C++: `lo + (hi - lo) // 2`
- Recursive version returns an index **relative to the slice** — slicing loses the offset and also copies the array. Always use the iterative pointer version.

**Complexity:** O(log n) time, O(1) space.

## Part 2 — Find First and Last Position (Modified Binary Search)

**Problem:** Find the first and last occurrence of a target in a sorted array. Return `[-1, -1]` if not found. Must be O(log n).

**Key:** Plain binary search stops at any match. Instead, **keep searching after a match** toward the boundary you care about:

```python
def searchRange(self, nums, target):
    def find(first):
        lo, hi, ans = 0, len(nums) - 1, -1
        while lo <= hi:
            mid = (lo + hi) // 2
            if nums[mid] == target:
                ans = mid              # record it, don't stop
                if first:
                    hi = mid - 1       # keep looking left for first
                else:
                    lo = mid + 1       # keep looking right for last
            elif nums[mid] < target:
                lo = mid + 1
            else:
                hi = mid - 1
        return ans
    return [find(True), find(False)]
```

**Bug I fixed first:** My initial attempt found one match, then walked left and right one step at a time. This is O(n) on `[8,8,8,8,8]` — fails the problem's O(log n) requirement. The correct approach never walks linearly.

**Complexity:** O(log n) — two binary searches.

## Part 3 — Valid Sudoku (Hash Set Constraint Checking)

**Problem:** Validate a 9×9 Sudoku board — no repeats in any row, column, or 3×3 box.

**Approach:** One pass. For each cell, generate three keys and check/add to a single set:

```python
def isValidSudoku(self, board):
    seen = set()
    for r in range(9):
        for c in range(9):
            val = board[r][c]
            if val == '.': continue
            row_key = (r, val)
            col_key = (val, c)
            box_key = (r // 3, c // 3, val)
            if row_key in seen or col_key in seen or box_key in seen:
                return False
            seen.update([row_key, col_key, box_key])
    return True
```

The box index `(r // 3, c // 3)` groups cells into one of 9 boxes. **O(81) = O(1) time and space** (fixed board size).

## Part 4 — Happy Number (Cycle Detection on a Sequence)

**Problem:** A number is "happy" if repeatedly replacing it with the sum of squares of its digits eventually reaches 1. If it loops forever (cycle), return `False`.

**Approach:** Use Floyd's slow/fast pointer — same cycle detection as Linked List Cycle, but on the digit-square sequence:

```python
def isHappy(self, n):
    def digit_sq(num):
        total = 0
        while num:
            num, d = divmod(num, 10)
            total += d * d
        return total

    slow, fast = n, digit_sq(n)
    while fast != 1 and slow != fast:
        slow = digit_sq(slow)
        fast = digit_sq(digit_sq(fast))
    return fast == 1
```

Alternatively, use a `seen` set — simpler but O(n) space. Floyd's is O(1) space.

## Part 5 — Count Servers that Communicate (Row/Column Count)

**Problem:** Servers communicate if they share a row or column with at least one other server. Count how many communicate.

**Approach:** Count servers per row and per column. A server communicates if `row_count[r] > 1` or `col_count[c] > 1`.

```python
def countServers(self, grid):
    rows, cols = len(grid), len(grid[0])
    row_count = [sum(grid[r]) for r in range(rows)]
    col_count = [sum(grid[r][c] for r in range(rows)) for c in range(cols)]
    return sum(
        1 for r in range(rows) for c in range(cols)
        if grid[r][c] == 1 and (row_count[r] > 1 or col_count[c] > 1)
    )
```

**O(rows × cols) time, O(rows + cols) space.**

## Part 6 — Find Servers That Handled Most Requests 🔴 Hard (Sorted Set + Heap)

**Problem:** `n` servers handle requests round-robin. Server `(arrival % n)` or the next available server handles each request. Find servers that handled the most requests.

**Key data structures:**
- `free`: `SortedList` of available server indices — O(log n) for search and removal
- `busy`: min-heap of `(finish_time, server_index)` — O(log n) for release

```python
from sortedcontainers import SortedList
import heapq

def busiestServers(self, k, arrival, load):
    free = SortedList(range(k))
    busy = []
    count = [0] * k

    for i, (t, l) in enumerate(zip(arrival, load)):
        # release servers that have finished
        while busy and busy[0][0] <= t:
            _, s = heapq.heappop(busy)
            free.add(s)

        if not free:
            continue   # all servers busy — this request is dropped

        # find the first server >= i % k (round-robin preference)
        idx = free.bisect_left(i % k)
        if idx == len(free):
            idx = 0    # wrap around to smallest available server
        server = free[idx]
        free.remove(server)
        heapq.heappush(busy, (t + l, server))
        count[server] += 1

    max_count = max(count)
    return [i for i, c in enumerate(count) if c == max_count]
```

**O((n + m) log k) time** — n = requests, m = release events, k = servers. `SortedList.bisect_left` gives O(log k) lookup of the preferred server.

## Binary Search Pattern Summary

| Variant | Modification |
|---|---|
| Classic | Stop at first match, return index |
| Find first occurrence | Record match, continue left (`hi = mid - 1`) |
| Find last occurrence | Record match, continue right (`lo = mid + 1`) |
| Search insert position | Same template, return `lo` when loop ends |
